# Lane models and face defaults
Availability describes configuration/probe evidence, not a successful inference health check.
Enrollment below comes from this lane's live configuration, never another installation's roster or credentials. A configured face default is not necessarily the selected per-turn backend; the runtime card reports that selection. Multiple roles can use one model. The platform checks a workflow's review policy when a proposal is made. If that policy cannot be met, the owner must explicitly choose "Start anyway with same-model review", and the downgrade is recorded. A known provider family does not establish an immutable model identity or independent review. A model critic is not an independent filesystem/test oracle.
Unavailable bindings fail explicitly. Do not request new keys or silently substitute providers. lmstudio is an OpenAI-protocol selector label, not proof the LM Studio app needs starting. No catalog or chat answer changes the platform's main model.
