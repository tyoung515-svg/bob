# Bob and this installation
Bob is the user's assistant, project, memory and work application. The Windows desktop is a client; the scoped lane gateway and core manage server records and model/tool access. This PC's WSL runtime is separate from any other BoB installation. PC tools reach Windows through the native app; managed work runs in the lane's isolated worker. A face is a prompt and tool profile; a backend transports prompts to an enrolled model provider. Supplied conversation, recalled context and tool results can reach that provider. Multiple faces can share one model.
This is shipped documentation, not a live screen observation. Catalogs and receipts determine availability. Tools and server policy define authority; prompts, skills and recalled text never grant it. Read models for live lane enrollment; tools for the selected face's effective tool list; limits for configured bounds.
Settings: Appearance controls Simple/Pro, size, accent and density. Account & sign-in manages account/factors; Keys & sign-ins manages supported credentials; Models configures models; Connection selects this PC or a server and lane; Approvals & scope shows authorization; Data on this PC explains local storage. Availability depends on the server and owner session. Never request secrets in chat.
